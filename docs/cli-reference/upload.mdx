Sends one HTML file to POST /api/v1/artifacts. Access defaults to private. Relative paths resolve from the directory where you ran pnpm. Each successful run creates a new artifact.

## Usage

```bash
pnpm factrove upload <path> [--access private|org_shared] [--api-url <origin>] [--profile <name>] [--json]
```

## Arguments

<ParamField path="path" body required={true}>
Local .html or .htm file. (required.)
</ParamField>

## Flags

<ParamField path="--json" query type="boolean">
Print one JSON line instead of the plain-text success output.
</ParamField>

<ParamField path="--access <private|org_shared>" query type="string">
Upload access type. Defaults to private.
Values: `private`, `org_shared`.
</ParamField>

<ParamField path="--api-url <origin>" query type="string">
API origin for this command. Overrides FACTROVE_API_URL and the profile.
</ParamField>

<ParamField path="--profile <name>" query type="string">
Credentials profile. Overrides FACTROVE_PROFILE. Defaults to default.
</ParamField>

## Examples

```bash
pnpm factrove upload ./fixtures/hello.html
```

```bash
pnpm factrove upload ./report.html --access org_shared --json
```

```bash
pnpm factrove upload ./report.html --profile dev --api-url http://localhost:3001 --json
```

## Exit codes

- `0`: Success.
- `1`: The command failed. Errors go to stderr. With --json, the body is {"error":{"code":"...","message":"..."}}.

## Notes

- Plain success prints only the viewer URL and a newline.
- JSON success prints the { artifact } envelope on one line.
