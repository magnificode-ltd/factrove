## Accepted flags

The help text above is exact. These flags are also accepted, including ones that help text does not list.

- `--name <name>` — Name shown in the library. One line, up to 120 characters.
- `--json` — Print one JSON line (alias: --output json).
- `--output <json|text>` — Print one JSON line when the value is json. --output text is the plain output.
- `--api-url, --endpoint-url <origin>` — API origin (alias: --endpoint-url).
- `--profile <name>` — Credentials profile (default: default). Accepted on every command. Help lists it on configure.
- `--quiet` — Accepted on upload, get, share, list, rename, and delete. It does not hide their output. Help does not list it. configure rejects it.
- `-h, --help` — Show help.

## Behavior

Plain success prints `Renamed {id}.` `--json` prints one `{ artifact }` line. The stored HTML, access, and any public link stay as they are. There is no way to clear a name.

`--name` uses the same one-line, 120-character rule as upload. Only the owner can rename. Anyone else gets `404 ARTIFACT_NOT_FOUND`, including an organization admin.
