Creates a public share for the artifact you own, or prints the existing one. --password prompts twice. --password-stdin reads a pipe. --remove-password keeps the URL and clears the password. --revoke removes the link. Use only one of those actions.

## Usage

```bash
pnpm factrove share <id> [--password | --password-stdin | --remove-password | --revoke] [--json] [--api-url <origin>] [--profile <name>]
```

## Arguments

<ParamField path="id" body required={true}>
Artifact UUID. (required.)
</ParamField>

## Flags

<ParamField path="--json" query type="boolean">
Print one JSON line instead of the plain-text success output.
</ParamField>

<ParamField path="--revoke" query type="boolean">
Remove the public link and its password.
</ParamField>

<ParamField path="--password" query type="boolean">
Prompt twice for a link password without echoing it. Needs a terminal.
</ParamField>

<ParamField path="--password-stdin" query type="boolean">
Read the link password from stdin. One trailing newline is removed.
</ParamField>

<ParamField path="--remove-password" query type="boolean">
Keep the public link and remove its password.
</ParamField>

<ParamField path="--api-url <origin>" query type="string">
API origin for this command. Overrides FACTROVE_API_URL and the profile.
</ParamField>

<ParamField path="--profile <name>" query type="string">
Credentials profile. Overrides FACTROVE_PROFILE. Defaults to default.
</ParamField>

## Exit codes

- `0`: Success.
- `1`: The command failed. Errors go to stderr. With --json, stderr is the common JSON error envelope.

## Notes

- Plain success prints the public link, whether it is password protected, and a newline.
- Plain --revoke prints a confirmation and does not print the old link.
- Plain --remove-password prints a confirmation. Passwords are 10 to 128 NFC characters and are never printed.
