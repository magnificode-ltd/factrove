Writes ~/.factrove/credentials and ~/.factrove/config with mode 0600. Directories Factrove creates for those files are mode 0700. The command does not print the key. An explicit --profile uses that profile's stored key later and ignores FACTROVE_API_KEY.

## Usage

```bash
pnpm factrove configure [--profile <name>] [--api-key <key>] [--api-url <origin>]
```

## Flags

<ParamField path="--api-url <origin>" query type="string">
API origin for this command. Overrides FACTROVE_API_URL and the profile.
</ParamField>

<ParamField path="--api-key <key>" query type="string">
API key to store. Prefer a prompt or stdin so the key stays out of shell history.
</ParamField>

<ParamField path="--profile <name>" query type="string">
Credentials profile. Overrides FACTROVE_PROFILE. Defaults to default.
</ParamField>

## Examples

```bash
pnpm factrove configure --profile default
```

```bash
pnpm factrove configure --profile dev --api-url http://localhost:3001
```

## Exit codes

- `0`: Success.
- `1`: The command failed. Errors go to stderr. With --json, stderr is the common JSON error envelope.

## Notes

- FACTROVE_CONFIG_DIR, FACTROVE_SHARED_CREDENTIALS_FILE, and FACTROVE_CONFIG_FILE override the file paths.
- When stdin is a terminal, the command prompts for a missing key and URL. Otherwise it reads the key and URL from two stdin lines.
