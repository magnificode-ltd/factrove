Calls GET /api/v1/artifacts/{id}/content. The default format is html, the stored bytes. --format markdown asks the API to convert that HTML on the way out. Markdown is not saved.

## Usage

```bash
pnpm factrove get <id> [--format html|markdown] [--json] [--api-url <origin>] [--profile <name>]
```

## Arguments

<ParamField path="id" body required={true}>
Artifact UUID. (required.)
</ParamField>

## Flags

<ParamField path="--json" query type="boolean">
Print one JSON line instead of the plain-text success output.
</ParamField>

<ParamField path="--format <html|markdown>" query type="string">
Content format for get. Defaults to html.
Values: `html`, `markdown`.
</ParamField>

<ParamField path="--api-url <origin>" query type="string">
API origin for this command. Overrides FACTROVE_API_URL and the profile.
</ParamField>

<ParamField path="--profile <name>" query type="string">
Credentials profile. Overrides FACTROVE_PROFILE. Defaults to default.
</ParamField>

## Examples

```bash
pnpm factrove get 123e4567-e89b-42d3-a456-426614174000
```

```bash
pnpm factrove get 123e4567-e89b-42d3-a456-426614174000 --format markdown --json
```

## Exit codes

- `0`: Success.
- `1`: The command failed. Errors go to stderr. With --json, the body is {"error":{"code":"...","message":"..."}}.

## Notes

- Plain success prints the content with no extra bytes.
- JSON success prints one line with format, mediaType, and content.
