# Feature requirements

`prd/` is one document per feature. Each file states the purpose, the behavior the code implements, and the constraints a later change has to keep. User guides live in [docs/](../docs/introduction.mdx). Repository layout and development commands live in [README.md](../README.md).

| Document | Feature |
| --- | --- |
| [artifacts.md](artifacts.md) | HTML artifacts, the library, the viewer, replace, rename, and delete |
| [sharing.md](sharing.md) | Public links and optional link passwords |
| [auth.md](auth.md) | Email and password sessions |
| [organizations.md](organizations.md) | The first organization and membership |
| [api-keys.md](api-keys.md) | Organization API keys |
| [cli.md](cli.md) | CLI commands, config precedence, and differences from `aws s3` |
| [storage.md](storage.md) | Object storage for artifact bytes |
| [self-host.md](self-host.md) | Running this repository yourself |
